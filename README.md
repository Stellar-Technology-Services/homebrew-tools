# Homebrew Tools

A Homebrew tap for tools maintained here.

## Install

```sh
brew tap Stellar-Technology-Services/tools
brew install kaas
```

`kaas` installs a prebuilt binary by default. To build from source instead:

```sh
brew install --HEAD kaas
```

## Formulae

- `kaas` — persistent local Linux workspaces for coding agents ([KaaS](https://github.com/Stellar-Technology-Services/kaas))
